# Fidel Mercado Tech — Guía de Identidad Visual

**Dominio:** fidelmercadotech.com  
**Marca:** Fidel Mercado Tech  
**Enfoque:** desarrollo de software, CRM, control de inventario, automatización, agentes de IA, soluciones web y productos tecnológicos para empresas.

---

## 1. Concepto de marca

Fidel Mercado Tech debe comunicar:

- Tecnología profesional y confiable.
- Desarrollo de software moderno.
- Inteligencia artificial aplicada a negocios.
- Automatización de procesos.
- Soluciones empresariales prácticas.
- Cercanía y acompañamiento técnico.
- Capacidad para crear productos digitales a medida.

La marca no debe verse como una tienda de computadores ni como una empresa de reparación técnica.  
El foco visual debe ser **software + IA + automatización + transformación digital**.

---

## 2. Logo

### Idea principal

El isotipo utiliza las iniciales **FM** en una forma geométrica y tecnológica.

Elementos sugeridos:

- Iniciales `F` y `M` integradas.
- Formas modulares o píxeles para representar datos y digitalización.
- Sensación de movimiento para transmitir automatización.
- Diseño suficientemente simple para funcionar como favicon, avatar e icono de aplicación.

### Construcción recomendada del nombre

**FIDEL MERCADO**  
**TECH**

También puede usarse la versión horizontal:

**FIDELMERCADOTECH**

### Tagline recomendado

> **Tecnología que impulsa tu negocio.**

Alternativa:

> **Software, IA y automatización para empresas.**

La segunda versión explica mejor lo que hace la marca y es especialmente útil en la página web.

## 4. Gradiente principal

```css

  135deg,
  #0066FF 0%,
  #00D9FF 100%
);
```

Puede utilizarse en:

- Logo.
- Botones destacados.
- Iconos.
- Ilustraciones.
- Números importantes.
- Elementos relacionados con IA.

No abusar del gradiente en textos largos.

## 8. Sombras

Usar sombras suaves.

Ejemplo:

```css
box-shadow:
  0 10px 30px rgba(7, 21, 38, 0.10);
```

En fondos oscuros puede utilizarse un glow muy sutil:

```css
box-shadow:
  0 0 30px rgba(0, 217, 255, 0.12);
```

## 15. Lenguaje de marca

La comunicación debe ser directa y entendible.

Evitar abusar de expresiones como:

- disrupción.
- revolución.
- ecosistema 360.
- soluciones de vanguardia.
- tecnología de última generación.

Preferir:

- Automatizamos procesos.
- Creamos software para tu empresa.
- Organizamos tus clientes y operaciones.
- Integramos inteligencia artificial.
- Reducimos tareas manuales.
- Centralizamos tu información.

## 22. Regla importante

La marca debe hacer que un cliente piense:

> **“Esta empresa crea tecnología y software serio para negocios.”**

No debe parecer:

- una tienda de electrónica;
- una empresa gamer;
- un servicio técnico de computadores;
- una marca de criptomonedas.
